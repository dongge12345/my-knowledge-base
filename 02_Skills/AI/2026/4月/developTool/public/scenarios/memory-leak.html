问题版

内存泄漏排查实验室

这个页面会反复挂载和卸载一个模拟组件。问题版故意不清理事件监听、定时器和大对象引用；修复版会在卸载时完整回收。你可以用 Memory 面板和快照对比。

打开问题版 打开修复版

操作区

重复点击挂载和卸载，或者直接跑几轮自动循环，再去 Memory 做 Heap Snapshot / Allocation Timeline。

你应该怎么查

  1. 打开 Memory，先做一次基线快照
  2. 反复执行挂载和卸载，或者直接自动循环
  3. 再做第二次、第三次快照，对比对象数量是否持续上涨
  4. 看有没有 Detached DOM、Array、Closure、EventListener 持续残留
  5. 切到修复版，重复同样操作，验证对象是否能回收
