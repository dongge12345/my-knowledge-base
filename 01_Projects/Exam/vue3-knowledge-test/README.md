        为什么vue3的useRoute后，通过route打印，无法获取路由来源的信息，只有当前路由的信息？
                因为useRoute()返回的是当前路由的信息，而不是路由来源的信息。如果需要获取路由来源的信息，需要在路由守卫中使用next()
        为什么每个组件需要用useRouter单独构建路由实例？
            组件里用 useRouter 稳如泰山，组件外用 import 迫不得已；SPA 虽简单但省钱省心，SSR 虽然快但代码要变。
            好的，为你精简总结如下：
                ### 1. 核心差异
                * **`useRoute`**：仅反映**当前**激活的路由状态（坐标），不记录历史。获取来源信息必须通过导航守卫（`beforeEach`）中的 `from` 参数。
                * **`useRouter` vs `import`**：前者是 Vue 3 的标准做法，通过依赖注入获取当前应用的路由实例；后者是 JS 模块单例。在**组件内**应优先使用 `useRouter` 以保证上下文正确。

                ### 2. SSR 与单例风险
                * **状态污染**：在 SSR 环境下，服务器为所有用户运行同一套代码。若直接 `import` 导出的单例路由，不同用户的请求会互相干扰、混淆页面数据。
                * **解决方案**：SSR 必须为每个请求创建独立的实例，而组件通过 `useRouter` 自动获取属于该请求的正确实例。

                ### 3. 渲染模式权衡
                * **SPA (你当前的模式)**：由浏览器渲染，服务器压力极小，开发简单，但 SEO 弱。
                * **SSR**：由服务器渲染 HTML，首屏快、SEO 好，但会消耗大量服务器 CPU 资源，且要求代码严谨（避免全局单例）。
