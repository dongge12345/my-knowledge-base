# Vue3 + Vite + TypeScript 2-4 周补强清单

## 目标

这份清单的目标不是“学完所有前端知识”，而是把自己补到一个更接近公司真实项目上手的状态。

更具体地说，希望达到下面这个水平：

- 能看懂并接手已有的 Vue3 + Vite 项目
- 能在现有代码结构下完成中小型需求
- 能较自然地写出 Vue3 + TS 的常见业务代码
- 遇到常见类型问题、路由问题、状态问题时，知道从哪里入手排查

---

## 当前阶段判断

基于目前已经学到的内容，可以认为自己已经具备了进入真实项目继续学习的基础，但还没有到“独立稳定负责复杂模块”的程度。

目前已经具备的能力包括：

- 理解 Vue3 + Vite + TypeScript 的基本关系
- 知道 `vite` 与 `typescript` / `vue-tsc` 的职责区别
- 能理解并使用基础的路由、组件、Pinia、Element Plus
- 开始掌握类型守卫、联合类型、`computed`、`Pick / Omit / Partial`
- 能感受到 TypeScript 的价值不只是“能写”，而是“能帮业务建模”

目前还需要继续补强的方向主要包括：

- Vue3 组合式 API 的熟练度
- 真实项目中的接口请求与异步状态处理
- 更完整的状态建模和组件抽象能力
- UI 库和表单表格场景的实战经验
- 工程化和项目协作层面的知识

---

## 第 1 周：Vue3 基础扎实化

### 重点目标

把 Vue3 组合式 API 和组件开发用顺手，避免“知道概念但写起来不自然”。

### 建议掌握内容

- 熟练掌握 `ref`、`reactive`、`computed`
- 理解 `watch` 与 `watchEffect` 的区别
- 明确什么时候使用 `computed`
- 明确什么时候使用 `watch`
- 掌握父子组件通信
- 理解 `props`、`emit`、`v-model`
- 理解 `defineProps`、`defineEmits`、`defineExpose`
- 掌握常见生命周期
- 能完成基础页面开发

### 这一阶段最重要的意识

- 源数据和派生数据要分清
- 能算出来的值尽量不要重复维护
- 组件之间的职责要尽量清楚

### 如果掌握得比较扎实，应该达到的状态

- 可以自己写出列表页、详情页、编辑页
- 能比较自然地拆出状态、事件、派生值
- 不会一遇到页面联动就本能地大量使用 `watch`

---

## 第 2 周：Vue Router + Pinia + TypeScript 业务建模

### 重点目标

把路由、状态管理和类型系统连起来，形成一个真实业务闭环。

### 建议掌握内容

- 掌握路由配置、嵌套路由、动态路由
- 理解 `params` 和 `query` 的区别
- 掌握路由守卫
- 理解登录拦截和权限页面访问流程
- 熟练使用 Pinia 定义 `state`、`getters`、`actions`
- 学会用联合类型描述状态
- 学会用类型守卫处理边界输入
- 学会使用 `Pick`、`Omit`、`Partial`

### 这一阶段最重要的意识

- 路由参数和 query 参数都属于不可信边界值
- 未登录、已登录、加载中、空数据等都应该被建模成明确状态
- 不要为了“兼容情况多”就把所有字段都改成可选

### 如果掌握得比较扎实，应该达到的状态

- 能自己做出登录拦截和登录回跳
- 能较清楚地区分 store 中的源状态与组件中的展示状态
- 能让 TypeScript 在业务层真正发挥作用，而不是只停留在语法层

---

## 第 3 周：接口请求与真实 CRUD 流程

### 重点目标

从“纯前端 demo”走向“更像真实项目”的开发方式。

### 建议掌握内容

- 学会封装请求工具
- 理解 API 层与组件层的职责区别
- 能为接口返回值编写类型
- 理解列表、详情、新增、编辑、删除的完整数据流
- 学会处理加载态、空态、错误态
- 理解异步请求下的状态切换
- 学会做提交后的数据刷新

### 这一阶段最重要的意识

- 组件最好不要直接写满所有请求逻辑
- 接口请求、状态维护、页面展示最好分层
- 类型不仅要写在组件里，也要写在 API 和数据模型里

### 如果掌握得比较扎实，应该达到的状态

- 能较顺畅地完成常见 CRUD 页面
- 能处理“请求中、请求成功、请求失败、无数据”这些现实情况
- 能开始看懂公司项目里比较常见的 API 组织方式

---

## 第 4 周：Element Plus + 工程化 + 阅读项目

### 重点目标

贴近公司项目的真实开发节奏，而不是只会做教程式小 demo。

### 建议掌握内容

- 熟练使用 Element Plus 的表单组件
- 熟练使用表格、弹窗、分页、输入框、选择器
- 掌握表单校验规则的写法
- 理解项目目录结构和模块组织方式
- 看懂 `package.json`、`README`、路由入口、store 入口
- 了解 `.env`、构建命令、类型检查命令
- 了解 lint、格式化、提交规范等协作工具的作用
- 练习阅读已有项目，而不是只从零开始写

### 这一阶段最重要的意识

- 公司项目最常见的工作不是“新建项目”，而是“理解并维护已有项目”
- 阅读代码和接手历史代码的能力，和写代码本身一样重要

### 如果掌握得比较扎实，应该达到的状态

- 进入一个 Vue3 + Vite 项目后不会只盯着单个组件
- 能从整体结构理解项目怎么跑起来
- 能较快找到自己需要修改的入口

## 当前最适合的学习方式

现阶段最适合的学习方式，不是继续零散地堆知识点，而是：

> 围绕一个真实的小业务闭环，反复练几遍。

比如：

- 登录
- 权限守卫
- 列表
- 详情
- 编辑
- 表单提交
- 类型建模

每做完一轮，都回头看：

- 哪些状态其实应该用联合类型
- 哪些展示结果应该用 `computed`
- 哪些类型其实可以从主模型派生
- 哪些边界值本来就不该直接进入业务逻辑

这样成长会比只看概念快很多。
