# 第 01 课：入口到首屏渲染

## 这节课要解决的问题

先不讲响应式、diff、Vuex。先把最外层链路看懂：

- 项目执行 `npm run dev` 后，代码从哪里开始跑
- `main.js` 做了什么
- `new Vue(...)` 到底做了什么
- `App.vue` 为什么会显示出来
- 路由为什么能接管页面内容

## 先看入口文件

入口文件是：

## 运行顺序

### 1. 先加载依赖

- 引入 Vue 构造函数
- 引入根组件 `App.vue`
- 引入路由实例 `router`
- 执行 Element UI 组件注册文件
- 执行全局样式文件

也就是说，在 `new Vue(...)` 之前，项目的基础能力已经准备好了：

- 组件系统可用
- 路由可用
- UI 组件已注册
- 全局样式已生效

### 2. 创建根实例

这一段最关键：

```js
new Vue({
  router,
  render: h => h(App)
})
```

这里可以先把它理解成：

- 创建一个 Vue 根实例
- 把 `router` 挂进去，让整个应用都能访问路由能力
- 告诉 Vue：根节点要渲染的不是模板字符串，而是 `App` 根组件

其中：

```js
render: h => h(App)
```

等价理解为：

```js
render(createElement) {
  return createElement(App)
}
```

意思是：根实例最终渲染出一个 `App` 组件节点。

### 3. 挂载到页面中的 `#app`

```js
.$mount("#app")
```

这一步的意义是：

- 找到 HTML 里的 `<div id="app"></div>`
- 把 Vue 根实例渲染结果挂进去

这个容器来自：

- [index.html](D:/data/paipaiHighLevel/02_Skills/AI/2026/3月/vue2+webpack/public/index.html)

核心节点是：

```html
<div id="app"></div>
```

## App.vue 为什么会显示出来

根原因很简单：

```js
render: h => h(App)
```

这里明确指定了根组件就是 `App`，所以挂载完成后，`#app` 里面显示的是 `App.vue` 的渲染结果。

对应文件：

- [App.vue](D:/data/paipaiHighLevel/02_Skills/AI/2026/3月/vue2+webpack/src/App.vue)

当前它的核心结构是：

```vue
<template>
  <div id="app">
    <div class="app-shell">
      <header class="header">
        <h1>Vue2 + Webpack 性能优化教学项目</h1>
        <p>分包、按需加载、工程化拆分</p>
      </header>
      <main class="main">
        <router-view />
      </main>
    </div>
  </div>
</template>
```

这个组件自己只负责两件事：

- 提供整体页面壳子
- 给路由页面留一个出口：`<router-view />`

## router-view 为什么能显示页面

路由配置在：

- [index.js](D:/data/paipaiHighLevel/02_Skills/AI/2026/3月/vue2+webpack/src/router/index.js)

当前核心代码：

```js
import Vue from "vue";
import Router from "vue-router";

Vue.use(Router);

const HomeView = () => import("@/views/Home.vue");
const HeavyView = () => import("@/views/Heavy.vue");

export default new Router({
  mode: "history",
  routes: [
    { path: "/", redirect: "/home" },
    { path: "/home", component: HomeView },
    { path: "/heavy", component: HeavyView }
  ]
});
```

这里的链路是：

### 1. `Vue.use(Router)`

把 `vue-router` 安装成 Vue 插件。安装后，Vue 获得这些能力：

- 识别 `<router-view />`
- 识别 `<router-link />`
- 每个组件实例上都能访问 `$router` 和 `$route`

### 2. 创建路由实例

```js
new Router({...})
```

这里定义了：

- URL 和页面组件的映射关系
- `/home` -> `Home.vue`
- `/heavy` -> `Heavy.vue`

### 3. 根实例注入 `router`

在 `main.js` 里：

```js
new Vue({
  router,
  render: h => h(App)
})
```

这一步让整个 Vue 应用都知道当前路由是谁、要显示哪个页面组件。

### 4. `router-view` 渲染当前匹配到的组件

当当前 URL 是 `/home` 时：

- `router` 匹配到 `HomeView`
- `<router-view />` 位置就渲染 `Home.vue`

当 URL 变成 `/heavy` 时：

- `router` 匹配到 `HeavyView`
- `<router-view />` 改为渲染 `Heavy.vue`

所以你可以把 `router-view` 理解成：

**当前页面组件的占位符。**

## 首屏渲染完整链路

把上面全部串起来，就是：

```text
npm run dev
-> webpack 启动开发服务并打包入口 main.js
-> 浏览器加载 bundle
-> 执行 main.js
-> 导入 Vue / App / router / element / 全局样式
-> new Vue({ router, render: h => h(App) })
-> $mount('#app')
-> Vue 把 App 渲染进 public/index.html 里的 #app
-> App 内部渲染页面壳子和 router-view
-> router 根据当前 URL 匹配到 Home.vue 或 Heavy.vue
-> router-view 渲染对应页面组件
-> 首屏显示完成
```

## 对比 React 的理解方式

如果拿 React 的项目式学习方式来对比，这一课对应的是：

- React 里的 `main.jsx` / `index.jsx` 入口
- `createRoot(...).render(<App />)` 的含义
- `App` 作为根组件如何承载路由出口
- `react-router` 如何根据 URL 决定渲染哪个页面

Vue2 这里只是写法不同，但整体链路是类似的：

- 都有入口文件
- 都有根组件
- 都有路由出口
- 都是“当前 URL -> 匹配页面组件 -> 渲染到页面”

## 这节课先记住的 4 个结论

1. `main.js` 是 Vue2 项目的运行入口。
2. `new Vue({ render: h => h(App) })` 的本质是“把 App 作为根组件渲染出来”。
3. `router-view` 不是普通标签，它是当前路由页面组件的占位符。
4. 页面最终显示哪个组件，不是 App 手动 `if/else` 控制，而是由 `vue-router` 根据当前 URL 匹配出来。
